# Product Goal

## Vision
Make `queue-lite` the go-to lightweight task queue for Node.js — simple API, zero dependencies, production-ready.

## Target Users
- Backend developers building API servers
- CLI tool authors needing parallel task execution
- Automation script writers

## Key Differentiators
- Zero dependencies
- Simple, intuitive API
- Built-in retry, timeout, priority
- TypeScript support
- Comprehensive documentation

## Success Metrics
- 100+ GitHub stars in 3 months
- Used in 5+ production projects
- <1ms overhead per task enqueue
- 100% test coverage

## Roadmap (Q1-Q2)
1. **v1.1.0** — TypeScript definitions + JSDoc
2. **v1.2.0** — Persistent queue (Redis/file backend)
3. **v1.3.0** — Dashboard UI for monitoring
4. **v2.0.0** — Plugin system for custom strategies
